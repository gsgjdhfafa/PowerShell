## Brave
| Shortcut | Funktion |
|----------|----------|
| Rechtsklick -> "In neuem Tab oeffnen"     | Link als neuer Tab |
| Rechtsklick -> "In neuem Fenster oeffnen" | Link als neues Fenster |
| Mittelklick auf Link                       | Neuer Tab (Hintergrund) |
| Strg + Klick                               | Neuer Tab (Hintergrund) |
| Strg + Shift + Klick                       | Neuer Tab (Vordergrund) |
| Shift + Klick                              | Neues Fenster |
| Strg + T / Strg + W                        | Tab oeffnen / schliessen |
| Strg + Shift + T                           | Geschlossenen Tab wieder oeffnen |
| Strg + Tab / Strg + Shift + Tab            | Tab vor / zurueck |
| Strg + 1..8 / Strg + 9                     | Tab N / letzter Tab |
| Strg + L                                   | Adressleiste fokussieren |
| Strg + N / Strg + Shift + N                | Neues Fenster / Inkognito |
| F6                                          | Zwischen Adresse + Seite springen |
